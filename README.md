# GOAT Store Manager (Reseller ERP)

## Опис проєкту та його призначення
GOAT Store Manager — це настільний WPF-застосунок, створений для автоматизації бізнесу продавців брендового одягу. 
Призначення системи: усунути ризики подвійних продажів унікального товару при поєднанні фізичного роздробу та онлайн-продажів, а також автоматизувати розрахунок чистого прибутку з урахуванням різних комісій маркетплейсів (OLX, Shafa) та податкових лімітів ФОП.

* **Олексій** — Backend/Core Engineer (Логіка C#)
* **Софія** — WPF/UI

## Використані технології
* **Мова програмування:** C#
* **Платформа:** .NET 8.0
* **Графічний інтерфейс:** WPF (XAML)
* **Патерн проєктування:** MVVM
* **База даних:** PostgreSQL (взаємодія через ADO.NET)
* **Тестування:** xUnit
* **CI/CD:** GitHub Actions

title
<b>Діаграма діяльності: Облік операцій продажу та повернення</b>
Ця діаграма описує процес фіксації операцій продажу та повернення через фізичний магазин і маркетплейси.
Вона демонструє перевірку залишків у єдиній базі, нарахування комісій онлайн-платформ,
паралельний розрахунок чистого прибутку та автоматичний контроль ліміту ФОП (>90%).
end title

start
:Користувач ініціює нову операцію в системі;

if (Тип операції?) then (Оформлення продажу)
  :Створення нової транзакції;
  
  repeat :Пошук товару в каталозі;
    :Введення назви, коду або специфікації (колір, тип);
    :Система шукає товар у єдиній базі інвентарю;
    if (Товар знайдено та Залишок > 0?) then (Так)
      :Додавання товару до списку продажу;
    else (Ні)
      :Помилка: "Товар відсутній або виникла десинхронізація";
    endif
  repeat while (Додати ще товар до чека?) is (Так)
  
  if (Чи є знижка?) then (Так)
    :Застосування знижки до окремих товарів або всієї суми;
  else (Ні)
  endif
  
  :Вибір каналу збуту;
  if (Канал збуту?) then (Маркетплейс)
    :Вибір конкретної платформи;
    :Система застосовує унікальне правило стягнення комісії для цієї платформи;
  else (Фізичний магазин)
    :Фіксація продажу без додаткової комісії маркетплейсу;
  endif
  
  :Вибір методу оплати (Картка або Готівка);
  :Підтвердження отримання коштів;
  
  fork
    :Система списує продані товари із загальних залишків;
    note left: Усунення ризику подвійних продажів\nунікального товару
  fork again
    :Вбудований калькулятор розраховує чистий прибуток;
    note right: (Ціна - Собівартість - Комісія маркетплейсу)
  fork again
    :Система додає суму транзакції до загального доходу ФОП;
  end merge
  
  :Перевірка поточного ліміту доходів ФОП;
  if (Загальний дохід ФОП > 90% від ліміту?) then (Так)
    :Система генерує попередження про наближення до ліміту;
    :Виведення рекомендації щодо використання альтернативних рахунків;
  else (Ні)
  endif
  
  :Транзакція успішно збережена в історії фінансів;
  :Генерація чека та запис у статистику;

else (Оформлення повернення)
  :Пошук попередньої транзакції в історії;
  :Вибір товарів, що повертаються;
  :Підтвердження повернення коштів клієнту (Картка/Готівка);
  
  fork
    :Повернення товару на склад (збільшення залишку);
  fork again
    :Списання суми з доходу та коригування чистого прибутку;
  end merge
  
  :Оновлення фінансової статистики;
endif

stop
